# Changelog

## 1.0.0
- First release: Scheduled / Sync On / Sync Off modes, daily window, optional Photo analysis and CloudKit pausing, safety helper, hideable menu bar icon, English-only UI.
- Deep pause: iCloud is frozen but released for 0.2 s every 2 s, runs for 10 s whenever an app launches, and resumes for 10 minutes if it stops answering, so apps never hang on it. Quit always resumes iCloud.
